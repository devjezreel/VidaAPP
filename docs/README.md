# 🙏 Igreja Cristã Ministério Vida - Website

Website oficial para apresentação do aplicativo da Igreja Cristã Ministério Vida e download do APK.

## 📱 Funcionalidades do App

- **📹 Vídeos dos Pastores** - Assista aos ensinamentos quando quiser
- **🙏 Pedidos de Oração** - Compartilhe com a comunidade
- **📅 Agenda de Eventos** - Fique atualizado sobre cultos e atividades
- **🎂 Aniversariantes** - Celebre os membros
- **📢 Publicações** - Receba notificações importantes
- **💰 Financeiro** - Acesso exclusivo para servos

## 🎨 Design

O website utiliza uma paleta de cores baseada no design do aplicativo:
- **Verde Principal**: #1a7d4d
- **Verde Claro**: #2d9b6f
- **Dourado**: #d4af37
- **Branco**: #ffffff
