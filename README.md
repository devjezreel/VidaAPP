# VidaAPP

Um aplicativo Android desenvolvido com **Jetpack Compose** e **Firebase** para gestão de comunidades, membros e atividades financeiras.

## 🚀 Funcionalidades

- **Gestão de Membros**: Cadastro e controle de membros da comunidade.
- **Conteúdos e Eventos**: Publicação de avisos, vídeos e agenda de eventos.
- **Pedidos de Oração**: Sistema para envio e acompanhamento de pedidos.
- **Controle Financeiro**: Registro de entradas e saídas.
- **Notificações**: Integração com Firebase Cloud Messaging (FCM).

## 🛠 Tecnologias

- **Kotlin** com **Jetpack Compose**
- **Firebase Firestore** (Banco de dados)
- **Firebase Cloud Messaging** (Notificações)
- **Coroutines & Flow** (Assincronismo)
- **ViewModel** (Arquitetura MVVM)

## 📦 Como rodar
1. Clone o repositório.
2. Adicione o seu arquivo `google-services.json` na pasta `app/`.
3. Sincronize o Gradle e execute o projeto.
